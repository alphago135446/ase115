数学里面通过理论公式推导π逐渐逼近于3.14，则做一个假设，只要有个理论公式这个规则，哪怕再嘈杂散乱的环境里面，都可以通过随机数无限循环，收敛，矫正达到理想状态，应用于现实中的发动机理论公式等等，因为有相关书籍原理，所以相对来说理论公式都是公开的 ，也可以训练成功，假如你有理论公式的一个数据，你想让这个例如：发动机达到理想状态，先用二次函数（回归分析）拟合这几个数值的大致走向，以优化控制这个发动机振动最小值或发电最大值等等，以实际测试效果的情况为准判断进行数据拟合，当找到数值可以达到最优状态时，再依据原理公式将数据带进去进行逆推，那样这个原理公式的大概模型就有了，我这是对现有神经网络进行改良
